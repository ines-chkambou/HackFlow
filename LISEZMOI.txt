SmartHackathon - HackFlow - Interface graphique (phase GUI)  |  Qt 6.7.3, qmake
=========================================================================
OUVRIR : Qt Creator > Fichier > Ouvrir un fichier ou un projet > SmartHackathon.pro > Ctrl+R
(Qt Designer seul n'active aucun bouton : il faut compiler le PROJET.)

CONVENTIONS DU DOCUMENT "BONNES PRATIQUES"
  - projet "SmartHackathon", systeme de build qmake
  - classe principale MainWindow : mainwindow.h / .cpp / .ui
  - UN SEUL fichier .ui ; les vues sont des pages de QStackedWidget
      stackedMain  : page 0 = Connexion, page 1 = application
      stackedPages : Accueil, Participants, Equipes, Projets, Mentors, Employes,
                     Equipements, Jury, Parametres

PARCOURS (document Word : Connexion -> Tableau de bord -> modules)
  Connexion --[Se connecter]--> Tableau de bord --[menu de gauche]--> chaque module
  application --[Deconnexion]--> Connexion

SEULS LES BOUTONS DE NAVIGATION FONCTIONNENT (+ la page Participants, voir plus bas)
  - Se connecter, les 9 entrees du menu de gauche, Deconnexion.
TOUS LES BOUTONS D'ACTION SONT VISUELS (aucun traitement branche)
  - Connexion : oeil du mot de passe, "Mot de passe oublie ?", "Creer un compte"
  - Employes : Ajouter, Vider, Consulter le profil, Affecter, Trier, Exporter,
    icones oeil / crayon / poubelle, cloche, Admin.
  Aucune verification de mot de passe : "Se connecter" ouvre directement le tableau de bord.

INTEGRER LE MODULE D'UN AUTRE MEMBRE
  Qt Designer > mainwindow.ui > stackedPages > choisir la page (ex. pageParticipants)
  et y deposer les widgets de la maquette. La page "Employes" (pageEmployes) est la notre.

INTEGRATION DU MODULE PARTICIPANTS (projet "le5er")
  - Les widgets sont dans mainwindow.ui, page "pageParticipants" (UN SEUL fichier .ui conserve).
    Les 6 noms deja pris par la page Employes ont recu le suffixe "Part" :
    btnAjouterPart, btnViderPart, btnTrierPart, btnExporterPart, comboRolePart, comboDispoPart.
  - La logique est dans participantscontroller.h / .cpp (classe ParticipantsController, creee dans le
    constructeur de MainWindow). Ajout / modification / suppression, filtres, tri, pagination,
    export CSV, piece jointe PDF (detection de l'equipe), sauvegarde participants.json, notifications.
  - Barre de recherche du haut (lineTopSearch) : filtre les participants quand la page Participants est affichee.
    Elle est videe a chaque changement de page.
  - Cloche (btnBell) : ouvre les notifications du module Participants (pastille rouge, SMS de confirmation).
  - Icones du module : dossier icons_participants/ (prefixe de ressources ":/part/") pour ne pas entrer
    en collision avec icons/ de HackFlow (ex. bell.png existe dans les deux).
  - Le style du module est applique uniquement a formPanel et tablePanel : les autres pages sont inchangees.
  - Qt PDF (facultatif) : si le module est installe, SmartHackathon.pro l'active tout seul (HAVE_QTPDF).
  - Donnees : participants.json et notifications.json dans le dossier AppData de l'application
    (nom d'application "HackFlow", donc different de l'ancien "Participants").
