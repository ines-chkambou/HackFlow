HACKFLOW - version fonctionnelle (Qt Widgets, C++11)

1. Ouvrir HackFlow.pro dans Qt Creator, choisir un kit Desktop Qt (Qt 6.x ou 5.15).
2. Build > Clean Project, puis Build > Rebuild Project, puis Run.

Fichiers : main.cpp, mainwindow.h, mainwindow.cpp, resources.qrc, assets/ (logo + ampoule).
design/maquette.png = ancienne image de reference (non utilisee par le programme).

Fonctionnalites : navigation laterale, recherche globale + recherche projets, filtres statut/equipe,
affichage liste/grille, Nouveau projet, Voir, Modifier, menu (...) : changer statut / supprimer,
statistiques, donut, projets par equipe et dernieres activites mis a jour en direct, notifications, Admin.
